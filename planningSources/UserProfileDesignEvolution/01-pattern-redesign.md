# Этап 1 — Редизайн узоров профиля (штриховые, в стиле приложения)

## Описание

Полная замена системы узоров фона профиля. Прежние 4 узора — **Полигоны
(`low_poly`)**, **Изометрия (`iso_grid`)**, **Нейронные нити (`neural_threads`)**,
**Точки (`dot_matrix`)** — не попадают в премиальный золото-тактический язык
приложения, а часть из них (изо-кубы, полигоны) имеет **заливку**, перекрывающую
выбранный цвет фона. Их нужно **полностью удалить**.

Взамен — **5 узоров только из тонких линий/штрихов (без заливки)**. Узор
накладывается поверх выбранного цвета фона и **не перекрывает его**: цвет фона
виден в просветах между штрихами и остаётся доминирующим.

## Пользовательский сценарий

В Интерфейс-Хабе пользователь оформляет облик: рамка → фон (цвет/градиент) →
стиль статов → вкладка **«Узоры»**. Выбирает узор и применяет. Узор **ложится
поверх выбранного цвета фона тонкими линиями** — цвет фона ясно виден. Узор
одинаково отображается в Интерфейс-Хабе, в настройках облика (live-preview),
в личном профиле и в **публичном профиле другого пользователя** (зритель видит
чужой фон + узор).

## Решения (зафиксированы)

- **Набор: 5 узоров** (все штриховые, без заливки):
  | slug | Название | Мотив | Анимация |
  |---|---|---|---|
  | `topo` | Топографика | Контурные линии рельефа (тактическая карта высот) | медленный дрейф изолиний |
  | `hud_grid` | Тактическая сетка | Сетка + крестики-засечки + угловые скобки | бегущая scan-линия |
  | `radar` | Радар | Концентрические кольца + засечки + луч-развёртка с хвостом | вращение луча |
  | `sphere_meridians` | Меридианы сферы | Тонкий wireframe-глобус (широты/долготы) | медленное вращение |
  | `guilloche` | Гильош | Переплетённые премиум-кривые (розетка) | сдвиг фазы |
- **Все узоры бесплатны** (`price_dp = 0`); редкость варьируется только ради
  цвета rarity-точки.
- **Цвет линий** наследует акцент выбранного фона (`background.accentColor`,
  иначе `SieColors.accent`), рисуется тонко (0.6–1.4px) с лёгким свечением.
- **Скрим карточки ослаблен** (тёмный только по краям: верх 0.16 / низ 0.20,
  центр прозрачный) — цвет фона виден ярко, текст остаётся читаемым.
- **Анимация** — бесшовная 8-секундная петля; reduce-motion → статичный кадр.

## Логика и поведение

### Видимость цвета фона (ключевое)

- Узор — слой штрихов поверх базы фона, **без `fill`** → цвет/градиент фона виден
  между линиями (покрытие штрихов мало).
- Скрим (`ProfileHeroCard`) ослаблен до краевого градиента, чтобы не притенять
  цвет фона в центре карточки.

### Рендер (минимум изменений в экранах)

Все экраны выводят узор через единый `ProfilePatternLayer` (карточка) и
`ProfilePatternThumb` (сетки магазина/облика) — меняется только внутренняя
реализация painter'ов и список слагов:

- `profile_pattern_layer.dart`: удалить painter'ы neural/dot/low_poly/iso;
  добавить `TopoPainter`, `HudGridPainter`, `RadarPainter`,
  `SphereMeridiansPainter`, `GuillochePainter` (все stroke-only); обновить
  `patternPainterForSlug()`; убрать ветку `legacyNeural`.
- `profile_hero_card.dart`: `showPattern = pattern != null`; ослабить скрим.
- `customization_screen.dart` (`_Preview`): убрать legacy-fallback
  `NeuralNetworkWidget` для узоров.

### Чистка долгов

1. Удалить мёртвый файл `packages/sie_core/lib/src/widgets/profile_patterns.dart`
   (`ProfilePatternRenderer`, схема `pattern_type`) и его экспорт из `sie_core.dart`.
2. `NeuralNetworkWidget` **оставить** — он ещё используется для превью **фонов**
   с `use_neural_pattern` (отдельная фича, не узор).
3. **Конфликт миграций.** Две миграции создавали `profile_patterns`
   (`20260613000001` — `pattern_type`/старые цены; `20260614000002` —
   `pattern_slug`/`image_url`). На чистом деплое второй `create table` падал —
   исправлено на `create table if not exists`.

## Схема данных (Supabase)

Таблица `profile_patterns`, `profiles.equipped_pattern_id`, RLS, `user_inventory`
(тип `profile_pattern`), трансляция в публичный профиль/лидерборд — **уже есть**,
переиспользуются. Меняется только каталог:

- Новая миграция `20260617000001_profile_patterns_redesign.sql`:
  1. снять оснащение старыми узорами (`profiles.equipped_pattern_id = null`);
  2. удалить старые из `user_inventory` и `profile_patterns`
     (`low_poly, iso_grid, isometric, neural_threads, dot_matrix`);
  3. вставить 5 новых (idempotent `on conflict (slug) do update`), все `price_dp = 0`;
  4. выдать стартовый `topo` всем пользователям.
- `supabase/schema.sql` — сид узоров синхронизирован с новыми 5.
- Конфликт create-table в `20260614000002` → `create table if not exists`.

> ⚠️ Миграцию нужно применить к Supabase (в окружении нет CLI). До применения
> старые узоры остаются в каталоге, новые не появляются.
