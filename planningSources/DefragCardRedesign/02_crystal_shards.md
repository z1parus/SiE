# Этап 2 — Кристаллы-осколки (3 полосы, формы, цветовой сплит)

## Описание

Парящие **геометрические кристаллы** между кольцами — главный «контент» мандалы.
Ключевое из референса: осколки расположены в **нескольких концентрических полосах**
(не на одной орбите), имеют **разные формы** (треугольники / ромбы / пятиугольники)
и **цветовое разделение** — холодная бирюза на левой половине, тёплое золото на правой.

## Пользовательский сценарий

Вокруг ядра в 3 кольцевых полосах парят прозрачные кристаллы-осколки. Левая
половина — холодные бирюзовые, правая — тёплые золотые. В анимации они то
рассыпаны по краю, то «дефрагментируются» — собираются в аккуратные орбитальные
полосы (метафора наведения порядка в сознании).

## Логика и поведение

### Раскладка по полосам (главное отличие от текущего)
- **3 концентрические полосы** (напр. радиусы `R*0.30`, `R*0.50`, `R*0.68`), на
  каждой по 6–10 осколков (внешние полосы — больше осколков).
- Углы распределены по кольцу со стаггером; деттерминированная статичная раскладка
  (как сейчас — без рандома на кадр, ради golden-стабильности).

### Формы кристаллов
- 3–4 типа `Path`: узкий ромб (есть), равносторонний треугольник, «осколок»-
  четырёхугольник, пятиугольник-кристалл. Тип выбирается детерминированно по индексу.
- Размер варьируется (внешние крупнее), у каждого — стеклянная заливка + светлая
  грань-блик (как сейчас: fill + stroke по альфе).

### Цветовой сплит (холод/тепло)
- По стороне: `cos(slotAngle) ≥ 0` → тёплый (`gold`/`goldLight`/`gold2`),
  иначе холодный (`cold`→ `kRimTealLight/Dark`). (Механизм уже есть — распространить
  на все полосы.)
- На границе (верх/низ) — плавный переход по близости к оси, чтобы шов не был резким.

### Анимация «дефраг»
- Цикл рассыпаны↔собраны (`smoothstep`), **разная фаза по полосам**: внутренняя
  полоса собирается первой, внешние — с задержкой (волной).
- Спойка центр→осколок проявляется по мере «сборки» (есть).
- Reduce-motion → собранный кадр.
- (зависит от ответа в roadmap) — возможен вариант «всегда собрано + только дрейф».

## Затрагиваемые модули

- `apps/central_hub/lib/widgets/defrag_preview.dart` — список `_shards` (по полосам),
  `_shardPath` (формы), цикл отрисовки (фаза по полосам, сплит).

## Схема данных

Не требуется (декор). Опц.: число «собранных» осколков = данные медитации (вопрос в roadmap).

## Этапы реализации

1. Перевести `_shards` на 3 полосы с разными радиусами/количеством/размерами.
2. Добавить 3–4 формы кристаллов в `_shardPath(type, size)`.
3. Распространить цветовой сплит на все полосы; сгладить шов у осей.
4. Фаза «дефрага» по полосам (волна).
5. `flutter analyze` + визуальная проверка; перегенерировать golden (или отключить
   на время итераций — см. вопрос 3 в roadmap).

## Открытые вопросы

1. Сколько осколков на полосу (плотность) — ближе к референсу (плотно) или умеренно?
2. Нужны ли «целые» кристаллы-пятиугольники (как в референсе) или хватит ромбов/треуг.?
3. Анимация: волновой «дефраг» или статичная собранная мандала + дрейф?
