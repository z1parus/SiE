# Сравнение размеров контекстных окон моделей в Antigravity CLI

Контекстное окно определяет объем данных (код, история чата, логи, файлы), которые модель может удерживать в памяти и анализировать за один запрос.

| Семейство моделей | Конкретная модель | Размер контекстного окна (в токенах) | Примерный эквивалент в коде / тексте | Сильные стороны и сценарии использования в Antigravity |
| :--- | :--- | :--- | :--- | :--- |
| **Gemini** (Google) | **Gemini Pro** (например, 1.5/3.5 Pro) | **2 000 000** | ~1 500 000 слов<br>~60 000+ строк кода<br>До 1 часа видео / 22 часов аудио | **Анализ всей кодовой базы:** Позволяет загрузить весь проект целиком, изучить структуру БД, прочитать огромные логи сборки без обрезания контекста. |
| **Gemini** (Google) | **Gemini Flash** (например, 1.5/3.5 Flash) | **1 000 000** | ~750 000 слов<br>~30 000 строк кода | **Быстрые рутинные действия:** Оптимально для простых изменений, быстрого выполнения консольных команд, чтения средних файлов и частых коротких итераций. |
| **Claude** (Anthropic) | **Claude Opus** (с режимом Thinking) | **200 000** | ~150 000 слов<br>~6 000 строк кода | **Сложная архитектура и логика:** Идеальна для написания сложных алгоритмов, проектирования новых фич и глубокого поиска трудновоспроизводимых багов. |
| **Claude** (Anthropic) | **Claude Sonnet** (3.5 / 4.x) | **200 000** | ~150 000 слов<br>~6 000 строк кода | **Основная модель разработки:** Лучший баланс скорости и качества написания качественного кода с аккуратным форматированием. |
| **GPT** (OpenAI) | **GPT-4o / GPT-4o-mini** | **128 000** | ~96 000 слов<br>~4 000 строк кода | **Локальные задачи и генерация:** Быстрая модель для небольших задач, написания простых скриптов или точечного исправления функций. |

---

### Практическое значение для Antigravity

> [!TIP]
> **Как эффективно комбинировать модели в работе:**
> 
> * **Используйте Gemini Flash**, когда нужно выполнять рутинные команды (например, `git status`, `db push`, накатывать миграции, делать релиз). Это происходит моментально.
> * **Используйте Gemini Pro**, когда вам нужно провести аудит кодовой базы, проанализировать всю архитектуру проекта или найти взаимосвязи между разрозненными файлами.
> * **Переключайтесь на Claude Opus / Sonnet**, когда переходите непосредственно к написанию сложного кода, созданию новых экранов с красивым UI или исправлению багов в сложной бизнес-логике.
