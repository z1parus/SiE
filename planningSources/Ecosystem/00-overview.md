# Экосистема SiE — взаимосвязь всех модулей

## Описание
Хаб SiE состоит из самостоятельных модулей (Планирование, Привычки, Фокус, Дыхание, Медитация), объединённых в один продукт. Сейчас связи между ними точечные и в основном односторонние:

- **Планирование ↔ Привычки** — `goal_habit_links` + `applyHabitBoost` (стрик привычки бустит прогресс цели). Односторонне: привычка → цель.
- **Планирование ↔ Фокус** — у focus-сессии есть `taskId`/`goalId`, `focusSecondsForGoal` сворачивает время глубокой работы на цель. Двусторонне.
- **Дыхание** (`calmness`, `moodEmoji`) и **Медитация** (`stateBefore`/`stateAfter`) — трекают состояние, но наружу его не отдают. Практически изолированы.
- Общая «валюта» **XP/DP** есть, но это только счёт, не связь.
- Ось **«Сферы жизни»** (`area`) есть только на привычках.

## Главный принцип
Не строить N×N попарных мостов (5 модулей = 10 пар = 10 интеграций и 10 кнопок в UI — это и есть «усложнение»). Вместо этого — **2–3 общих слоя («шины»), в которые каждый модуль пишет и из которых читает**. Модули связываются транзитивно через общий слой; новый модуль подключается один раз.

## Порядок реализации (roadmap)
1. **`01-meditation-breathing-integration.md`** — переработка дыхания в модуле медитации: убрать текущую упрощённую реализацию (паттерны box/4-7-8/coherence прямо в `MeditationSessionProvider`) и напрямую соединить модули Медитации и Дыхания настоящим функционалом. Это подготовительный этап — он относится к экосистемности напрямую и убирает дубль-реализацию.
2. **`02-pillar-activity-habit.md`** — Опора 1: активность модуля авто-выполняет привычку (`activity → habit`). Один механизм соединяет Фокус/Дыхание/Медитацию/Планирование → Привычки.
3. **`03-pillar-operative-state.md`** — Опора 2: «Состояние оперативника» (Тонус/Готовность) — петля работа↔восстановление. Вытаскивает Дыхание/Медитацию из тупика.
4. **`04-pillar-life-areas.md`** — Опора 3: «Сферы жизни» как общая ось для сквозных срезов и умных подсказок.

## Как это покрывает все 10 пар
| Пара | Через что |
|---|---|
| План–Привычки | boost (есть) + обратно: цель предлагает/линкует привычки (Опора 3) |
| План–Фокус | task deep-work (есть) |
| План–Дыхание | Состояние: перед важной задачей — «боевая готовность» (Опора 2) |
| План–Медитация | Сферы + еженедельная рефлексия (Опора 3) |
| Привычки–Фокус | activity→habit (Опора 1) |
| Привычки–Дыхание | activity→habit (Опора 1) |
| Привычки–Медитация | activity→habit (Опора 1) |
| Фокус–Дыхание | Состояние: перерыв Pomodoro = дыхание (Опора 2) |
| Фокус–Медитация | центрирование до / рефлексия после (Опора 2) |
| Дыхание–Медитация | Этап 1 (эта переработка) |

## Гардрейлы против усложнения
- Всё **опционально и с умными дефолтами** — связи работают в фоне, настраивать не обязательно.
- **Витрина связей — в Оперативной сводке**, а не новыми экранами: Тонус, авто-выполненные привычки, подсказки практик — как системные сообщения в уже готовой ленте. Сводка становится «мозгом» экосистемы.
- **Ноль новых обязательных действий** — модули работают как раньше, связи только добавляют смысла.
