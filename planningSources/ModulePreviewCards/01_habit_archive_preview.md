# Этап 1 — Превью HABIT ARCHIVE (тепловая сетка консистентности)

## Описание

Заменить статичную захардкоженную сетку 5×5 точек (`_HabitMatrixPreview`) на
**тепловую сетку консистентности** (contribution / heatmap-grid в духе GitHub),
построенную на реальных `logDates`, с **флейм-бейджем серии**. Это мгновенно
читается как «трекер привычек»: видно ритм выполнения за последние недели и
текущую серию.

## Пользовательский сценарий

Пользователь листает карусель модулей и видит карточку HABIT ARCHIVE. На превью —
аккуратная сетка клеток, где каждая клетка = день; чем ярче золото, тем больше
привычек выполнено в тот день. Сегодняшняя клетка мягко пульсирует («отметься
сегодня»). В углу — маленький флейм с числом текущей серии. При первом появлении
клетки зажигаются волной слева-направо (прошлое → сегодня). Всё спокойно
анимировано и не отвлекает.

## Варианты дизайна

### Вариант A — «Тепловая сетка консистентности» ✅ рекомендованный
- Грид **7 строк × N колонок** (строки = дни недели, колонки = недели; ~5–7
  недель помещается). Каждая клетка — скруглённый квадрат.
- **Интенсивность клетки** = плотность выполнения в этот день:
  `doneCount(day) / scheduledCount(day)` (или просто число выполненных привычек),
  раскладывается в 4–5 ступеней alpha золотого акцента; пустой день — `c.border`.
- **Флейм-бейдж** (угол) = максимальная текущая серия среди привычек
  (`streaks.values.max`), иконка огня + число.
- Сильно ассоциируется с habit-трекингом, информативно (видно ритм + серию),
  не пересекается с кольцами planning-карточки.

### Вариант B — «Серии-стек» (альтернатива)
- 3 строки = топ-привычки (закреплённые/с наибольшей серией). В каждой: иконка +
  цвет привычки, недельная лента из 7 точек (последние 7 дней done/missed),
  число серии с флеймом.
- Очень буквально и per-habit информативно, но плотнее по контенту и сложнее
  влезает в маленькое превью; иконки привычек могут быть пустыми.

### Вариант C — «Кольца-привычки» (отклонён)
- Мини-кольца по привычкам. **Отклонено** — дублирует planning-превью (кольца).

**Решение:** A (тепловая сетка) как основной; флейм-серия — обязательный акцент.
Опционально позже — переключение A/B по плотности данных.

## Логика и поведение

### Привязка к данным
- Окно: последние `7 * weeks` дней (например `weeks = 6` → 42 дня), выровненные
  по неделям так, чтобы **правый-нижний угол = сегодня**.
- Для каждого дня `d` (ключ `yyyy-MM-dd`):
  `doneCount(d) = число habitId, у которых d ∈ logDates[habitId]`.
  `scheduledCount(d) = habitsState.dueOn(d).length` (для нормировки).
  `intensity(d) = scheduledCount>0 ? doneCount/scheduledCount : (doneCount>0?1:0)`.
- Ступени alpha: `[0.0→border, 0.25, 0.5, 0.75, 1.0]` золотого `c.accent`.
- **Серия:** `streak = (streaks.values.isEmpty) ? 0 : streaks.values.reduce(max)`.

### Анимация (рекомендованная связка A + B + C из roadmap)
- **Каскад-заполнение (появление):** один `AnimationController` (~1.2 сек, не
  зацикленный или зацикленный с длинной паузой); клетка `i` появляется (scale
  0.6→1 + fade) с задержкой по диагонали `delay = (col+row) * k`. Создаёт волну
  прошлое→сегодня.
- **Петля-шиммер (idle):** зацикленный контроллер (~6–8 сек): по сетке слева-
  направо пробегает лёгкая полоса повышенной яркости (диагональ), едва заметно.
- **Пульс «сегодня»:** клетка текущего дня дышит alpha (0.7↔1.0, ~2 сек).
- **Флейм-фликер:** иконка серии чуть меняет scale/opacity по шуму.
- **Reduce-motion:** статичный кадр — сетка полностью заполнена по данным, без
  каскада/шиммера/пульса; флейм статичен.

### Пустые состояния
- **Нет привычек** (`habits.isEmpty`): бледная пустая сетка (`c.border`) + по
  центру/углу мелкая подпись-намёк (например иконка `add_task`), без флейма.
- **Есть привычки, но нет логов:** сетка из пустых клеток + флейм `0`.
- Лоадинг (`habitsProvider` loading): пустая сетка-скелет без анимации данных.

### Геометрия (превью ~150×нечто, flex 5)
- Клетка ~12–14px, gap ~4px; 7 строк помещаются по высоте, колонки — сколько
  влезает по ширине (вычислять `cols` из доступной ширины в `LayoutBuilder`,
  либо фикс. `cols=6..7`). Скруглённые квадраты (`RRect`, r≈3).
- Флейм-бейдж — верхний-правый угол, поверх сетки, мелкий.

## Схема данных

Изменений в БД/Supabase **не требуется** — всё из уже загруженного
`habitsProvider`. Чистое UI-изменение превью.

## Этапы реализации

1. Вычислитель данных: функция `heatmapCells(habitsState, weeks)` → матрица
   интенсивностей + `currentStreak`. Юнит-логика без UI.
2. Painter `_HabitHeatmapPainter` (сетка скруглённых клеток по интенсивности,
   подсветка «сегодня»). Статичный рендер на данных.
3. Анимация: каскад-появление + петля-шиммер + пульс «сегодня»; reduce-motion →
   статичный кадр.
4. Флейм-бейдж серии (иконка + число), лёгкий фликер.
5. Пустые/лоадинг состояния.
6. `flutter analyze` затронутого файла; визуальная проверка (тёмная/светлая тема,
   0 / 1 / много привычек, пустые логи).

## Открытые вопросы

1. **Окно сетки:** 6 недель (42 дня) ок, или больше/меньше? (зависит от ширины
   карточки — уточнить визуально).
2. **Нормировка интенсивности:** делить на `scheduledCount` (доля выполнения) или
   брать абсолютное число выполненных привычек за день? (доля честнее, но при 1
   привычке всегда 0/1).
3. **Статус-подпись:** менять на серию (`🔥 N`) или оставить `"$count Active"`?
4. **Цвет клеток:** только золото (консистентно), или подмешивать цвет привычки
   при доминировании одной? (рекоменд. — только золото, чтобы не пестрило).
