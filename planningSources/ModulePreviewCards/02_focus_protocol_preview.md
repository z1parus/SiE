# Этап 2 — Превью FOCUS PROTOCOL (живое кольцо-таймер)

## Описание

Заменить статичную дугу `0.65` + хардкод `15:00 FOCUS` (`_FocusRingPreview` /
`_ArcPainter`) на **живое кольцо-таймер**, отражающее реальное состояние
`focusTimerProvider`, с **рядом точек-сессий за сегодня** и набором анимаций,
ассоциирующихся с концентрацией (дыхание кольца, светящийся ведущий кончик дуги,
фазовый цвет work/break, режим-ожидания «радар» в idle).

## Пользовательский сценарий

На карточке FOCUS PROTOCOL — кольцо с таймером в центре.
- **Idle (таймер не запущен):** кольцо показывает сконфигурированное время
  (`25:00`) и метку `READY`, дуга пустая; по треку медленно обходит одиночная
  светящаяся засечка (режим ожидания), кольцо едва дышит. Снизу — ряд точек:
  сколько помодоро уже сделано сегодня.
- **Work (идёт сессия):** дуга растёт по `progress`, в центре живое `MM:SS`,
  метка `WORK`, цвет золотой; на конце дуги пульсирует яркая точка; периодическая
  «минутная рябь». Кольцо дышит чуть активнее.
- **Break:** то же, но цвет холодный, метка `BREAK`.

Это мгновенно читается как «таймер фокуса», живёт реальными данными и красиво
анимировано.

## Варианты дизайна

### Вариант A — «Живое кольцо-таймер» ✅ рекомендованный (основа)
- Сохраняем кольцо (узнаваемо как таймер), но **завязываем на состояние**:
  idle → `settings.workMinutes:00` + `READY`, `progress=0`; work/break → живые
  `formattedTime` + `progress` + метка фазы.
- **Фазовый цвет:** work → `c.accent` (золото) → `c.accentSecondary`; break →
  холодный токен (напр. `c.accent` приглушённый/синеватый — уточнить токен).
- **Светящийся ведущий кончик** дуги прогресса (яркая точка с glow), пульсирует.

### Вариант B — «Ряд точек-сессий» (дополнение к A) ✅
- Под кольцом — ряд из N точек = помодоро **сегодня**
  (`bootcampDailyActivityProvider.focusSessionsToday`): заполненные = сделано,
  пустые = до некоторой цели (напр. min 4). Следующая-к-заполнению чуть пульсирует.
- Добавляет реальные данные и ощущение прогресса дня.

### Вариант C — «Сходящиеся кольца» (отклонён как основа)
- Несколько колец, стягивающихся к центру (метафора сужения внимания). Красиво,
  но **дублирует** мульти-кольца planning-превью → отклонено. Допустимо как
  отдельный idle-эффект, но не основной мотив.

**Решение:** A (живое кольцо) + B (точки-сессии) — основная связка.

## Логика и поведение

### Привязка к данным
```
final s = focusTimerProvider;
final idle = s.phase == FocusPhase.idle;
final timeText = idle ? '${s.settings.workMinutes}:00' : s.formattedTime;
final label    = switch (s.phase) {
  FocusPhase.work => 'WORK', FocusPhase.breakTime => 'BREAK', _ => 'READY' };
final progress = idle ? 0.0 : s.progress;          // 0..1
final running  = s.isRunning;
final doneToday = bootcampDailyActivityProvider.focusSessionsToday;  // int
```
- Точки-сессии: `count = max(target, doneToday)`, target по умолчанию 4;
  заполнено `doneToday`.

### Анимация (рекомендованная связка A + B + D из roadmap)
- **Дыхание кольца (всегда):** `AnimationController` ~4 сек, `reverse:true`;
  лёгкий scale (0.97↔1.0) + вариация alpha трека. Спокойный ритм концентрации.
- **Ведущий кончик (work/break):** на конце дуги — точка с `MaskFilter.blur`
  glow, пульс яркости в такт дыханию/секунде.
- **Idle-радар:** при `idle` по полному треку медленно (~5 сек, петля) обходит
  одиночная светящаяся засечка (режим ожидания вместо пустого статичного кольца).
- **Минутная рябь (опц., running):** раз в петлю — расходящееся полупрозрачное
  кольцо от трека (ощущение хода времени).
- **Фазовый цвет:** интерполяция/выбор палитры по `phase`.
- **Пульс точки-сессии:** следующая незаполненная точка дышит.
- **Reduce-motion:** статичный кадр — кольцо по `progress` (или idle-полный круг
  трека), без дыхания/радара/ряби; точки статичны.

### Состояния
- **Idle:** `25:00 / READY`, дуга пустая, радар-засечка, точки-сессии за сегодня.
- **Work/Break:** живое время, дуга по прогрессу, фазовый цвет/метка, кончик-glow.
- **Running glow:** при `isRunning` — общий лёгкий внешний glow кольца (живость).
- Провайдеры `bootcamp`/`analytics` в loading → точки скрыть/показать скелет.

### Геометрия
- Кольцо ~110–120px (как сейчас 140 бокс), центр — `MM:SS` (крупно) + метка
  (мелко, letterSpacing). Ряд точек — под кольцом, мелкие (∅5–6px, gap 5).
- Дуга: `strokeWidth ~7`, `StrokeCap.round`, старт `-π/2`, по часовой.

## Этапы реализации

1. Привязка состояния: idle/work/break → время/метка/прогресс/цвет (без новой
   анимации) — заменить хардкод реальными данными.
2. Painter: ведущий кончик с glow + фазовый цвет; дыхание кольца.
3. Idle-радар (бегущая засечка) + (опц.) минутная рябь в running.
4. Ряд точек-сессий за сегодня (`focusSessionsToday`), пульс следующей.
5. Reduce-motion → статичный кадр; loading-состояния провайдеров.
6. `flutter analyze`; визуальная проверка (idle/work/break, тёмная/светлая тема,
   0 и N сессий сегодня).

## Открытые вопросы

1. **Холодный цвет break:** есть ли подходящий токен в `SieColors`, или ввести
   (напр. приглушённый сине-стальной)? Нужно решить, чтобы не хардкодить.
2. **Цель точек-сессий:** фикс. 4, или брать из настроек/таргета дня? (по
   умолчанию 4, если нет источника).
3. **Статус-подпись:** менять на живое время/сессии или оставить `"25 min"`?
4. **Минутная рябь:** включать или это перегрузит маленькое превью? (по вкусу,
   за флагом).
5. **Idle-радар vs полностью статичное idle-кольцо** — радар оживляет, но если
   мешает, оставить только дыхание.
