# Редизайн превью-карточек модулей (Operations Control)

> Карусель модулей на главном экране (`operations_control_screen.dart`,
> `_BranchCarouselCard`). Каждая карточка = верхнее превью (flex 5) + подпись
> со статусом (flex 3). Цель этой итерации — превратить превью **HABIT ARCHIVE**
> и **FOCUS PROTOCOL** в красивые, информативные, анимированные и **завязанные на
> реальные данные** визуализации, мгновенно ассоциирующиеся со своим модулем.

---

## Принципы (общие для всех превью)

1. **Опора на стиль приложения.** Только токены `SieColors` / `SieMotion`.
   Золотой акцент (`c.accent`), без хардкод-цветов (как сейчас teal в planning).
2. **Реальные данные.** Превью показывает живое состояние модуля, а не
   декоративную заглушку (сейчас обе карточки статичны и захардкожены).
3. **Анимация — бесшовная петля + reduce-motion.** Лёгкая, ненавязчивая, 60fps,
   гаснет в статичный кадр при выключенной анимации ОС (`SieMotion.enabled`).
4. **Узнаваемость за 0.5 сек.** Habit → консистентность/серии; Focus → таймер/
   концентрация. Метафора считывается мгновенно.
5. **Без дублирования.** Planning-превью уже использует **кольца** → Habit и Focus
   должны выглядеть иначе (Habit — тепловая сетка; Focus — живое кольцо-таймер с
   дыханием, визуально отличное от planning-колец).
6. **Производительность.** Один `AnimationController` на карточку, `RepaintBoundary`
   уже оборачивает список; вычисления данных — дешёвые (итерация по уже
   загруженным провайдерам).

## Доступные реальные данные

**Habit** (`habitsProvider` → `HabitsState`):
- `habits: List<Habit>` (активные, закреплённые сверху), у `Habit`: `title`,
  `icon`, `color`, `polarity`, `schedule`.
- `logDates: Map<String, Set<String>>` — habitId → даты `yyyy-MM-dd`, когда цель
  выполнена. → база для **тепловой сетки** (плотность выполнения по дням).
- `streaks: Map<String, int>` — текущая серия по привычке. → **флейм-серия**.
- `dueOn([day])` — какие привычки запланированы на день.

**Focus** (`focusTimerProvider` → `FocusTimerState`):
- `phase` (`idle`/`work`/`breakTime`), `progress` (0..1), `formattedTime` ("MM:SS"),
  `isRunning`, `settings.workMinutes`, `completedSessions`.
- `bootcampDailyActivityProvider.focusSessionsToday: int` — помодоро сегодня.
- (опц.) `analyticsProvider.focusByDay.last.minutes` — минуты фокуса сегодня.

## Сводка предложенных анимаций (для быстрого выбора)

**HABIT ARCHIVE (тепловая сетка):**
- A. **Каскад-заполнение** — при появлении ячейки зажигаются диагональной волной
  (прошлое → сегодня); петля — лёгкий «шиммер», бегущий по сетке раз в ~6–8 сек.
- B. **Пульс «сегодня»** — колонка/ячейка текущего дня дышит (alpha), зовёт
  «отметься сегодня».
- C. **Флейм-фликер** — иконка серии чуть мерцает (scale/opacity-шум).

**FOCUS PROTOCOL (кольцо-таймер):**
- A. **Дыхание кольца** — всё кольцо слабо дышит масштабом/яркостью (~4 сек) —
  ритм спокойной концентрации.
- B. **Светящийся кончик дуги** — яркая точка на конце прогресса пульсирует; в
  idle — одиночная засечка-«радар» медленно обходит трек (режим ожидания).
- C. **Минутная рябь** — периодический расходящийся импульс-кольцо (ощущение хода).
- D. **Фазовый цвет** — золото (work) ↔ холодный (break).

Рекомендованные связки помечены в каждом файле этапа.
