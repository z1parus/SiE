# Этап 2 — Превью «Дефрагментация» (meditation) в стекле

## Описание

Перевести `_MeditationPreview` (плоский бирюзовый орб + ряби) в общий стеклянный
каркас с **героем — стеклянной «сферой спокойствия»**, внутри которой медленно
расходятся концентрические волны (мотив дефрагментации/очищения сознания).

## Пользовательский сценарий

На карточке — стеклянная сцена (диски + орбита + пилюли), в центре глянцевая
сфера с мягким золотым (или бирюзовым — см. вопрос) ядром; внутри неё спокойно
пульсируют концентрические волны. Дыхание сферы медленное и расслабляющее.

## Логика и поведение

### Герой
- **Стеклянная сфера** (глянцевый шар с единым светом сверху-слева, риммка как у
  breathing) — заменяет плоский орб.
- **Внутренние волны** — концентрические окружности, расходящиеся изнутри к краю
  сферы и затухающие (перенести идею текущих `_MeditationRipplePainter`, но
  **внутрь** сферы, а не наружу).
- **Дыхание** — медленный scale 0.94↔1.06 (как сейчас), ~5 сек.

### Цвет
- **Вариант A (рекоменд. — бренд):** золотое ядро (accent), как у HABIT/остальных
  — единый язык приложения.
- **Вариант B (идентичность):** сохранить фирменную бирюзу (`kRimTeal`) как метку
  медитации; тогда meditation — единственный «холодный» модуль (осознанный выбор).

### Анимация
- Орбита + float + пилюли (каркас) + внутренние волны + дыхание сферы.
- Reduce-motion → статичная сфера с одной-двумя статичными волнами.

## Затрагиваемые модули

- `operations_control_screen.dart`: `_MeditationPreview` →
  `GlassPreviewScene` + герой-сфера с внутренними волнами; переиспользовать
  `SphereRimPainter`.
- (палитра) `session_orb_painters.dart` — `kRimTeal*` / `kRimGold*`.

## Схема данных

Не требуется. (Опц. пилюли могли бы кодировать дни zen-streak — отдельно.)

## Этапы реализации

1. Поставить meditation на каркас (диски/орбита/пилюли).
2. Герой: стеклянная сфера + риммка (свет сверху-слева).
3. Внутренние концентрические волны (клиппинг по кругу сферы), затухание.
4. Дыхание сферы; reduce-motion статичный кадр.
5. `flutter analyze` + визуальная проверка (тёмная/светлая).
