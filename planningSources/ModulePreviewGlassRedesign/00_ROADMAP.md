# Glass-редизайн превью модулей (под уровень HABIT ARCHIVE)

> Привести превью **«Дефрагментация» (meditation)**, **PLANNING DEPARTMENT**,
> **FOCUS PROTOCOL** и **BREATHING PRACTICES** к тому же «свежему» языку, что и
> новое превью **HABIT ARCHIVE** (glassmorphic 3D-иконка), сохранив уникальную
> метафору каждого модуля.

---

## Почему HABIT ARCHIVE сейчас выглядит лучше (анализ)

| Критерий | HABIT ARCHIVE (свежо) | Остальные 4 (сейчас) |
|---|---|---|
| **Глубина / слои** | Многослойная сцена: матовые диски, блюр-свечения, тени → ощущение 3D-пространства | Плоский один слой, без глубины |
| **Материал** | Огранённое стекло + глянцевые блики + внутреннее свечение ядра | Плоские штрихи/градиенты |
| **Смысловой символ** | Чёткий «герой» — галочка в кристалле | Абстрактно: кольца, орб, дуга |
| **Композиция** | Фон (орбита) → средний план (диски) → герой (кристалл) → парящие акценты (пилюли) | Один центрированный элемент |
| **Свет** | Единый источник сверху-слева, согласованные блики/тени | Нет единой светотени |
| **Бренд** | Золото (accent) | planning/focus — золото; **meditation — бирюза (выбивается)**; breathing — золото |

**Вывод:** «свежесть» HABIT — это не картинка, а **система**: стеклянная
многослойная сцена + золотой глянцевый герой + парящие индикаторы + единый свет.
Достаточно вынести эту систему в переиспользуемый каркас и подставить в каждый
модуль свой центральный символ.

## Текущее состояние превью

- **HABIT ARCHIVE** — `_HabitCrystalPainter`: диски, орбитальные стрелки,
  огранённый золотой кристалл с ядром, галочка, парящие золотые пилюли. ✅ эталон.
- **Дефрагментация** — `_MeditationPreview`: бирюзовый орб (radial) + расходящиеся
  «ряби» + риммка. Плоско, один элемент, **бирюза**.
- **PLANNING DEPARTMENT** — `_PlanningPreview`: 3 вращающихся золотых кольца-
  миссии + `%` в центре. Чисто, но плоские штрихи.
- **FOCUS PROTOCOL** — `_FocusRingPreview`: одно золотое кольцо-таймер + время +
  точки-сессии. Плоско.
- **BREATHING PRACTICES** — `_BreathSpherePreview`: золотая шейдер-сфера + корона
  + риммка. Богаче прочих, но без стеклянной сцены/слоёв/парящих акцентов.

## Дизайн-система «Glass Scene» (ядро редизайна)

Единый каркас (общий для всех превью), извлечённый из HABIT:

1. **Слой фона** — матовые стеклянные диски (2 шт.) + мягкое блюр-свечение-плита.
2. **Орбитальный акцент** — тонкая вращающаяся дуга со стрелкой (+ пунктир) —
   мотив процесса/синхронизации.
3. **Герой-символ** — центральный глянцевый объект модуля с золотым ядром и
   единым светом сверху-слева (огранка/сфера/кольцо — зависит от модуля).
4. **Парящие пилюли** — 3 индикатора (золотой градиент COMMANDER) с
   последовательным появлением; несут данные модуля или декоративны.
5. **Тема-зависимость** (стекло видно на светлой и тёмной теме) + **reduce-motion**.

Каркас параметризуется «builder'ом героя», размер — единый **бокс 150** (уже
приведено в прошлой итерации).

## Сводка анимаций (свежие, по модулям)

- **Общие (каркас):** вращение орбиты + плавный float героя + последовательные пилюли.
- **Meditation:** медленные внутренние концентрические волны + дыхание сферы.
- **Planning:** вращение колец-миссий (уже есть) как ядро кристалла.
- **Focus:** дыхание кольца + светящийся ведущий кончик + idle-радар (уже есть).
- **Breathing:** пульс шейдер-сферы (уже есть) + орбита/пилюли каркаса.
