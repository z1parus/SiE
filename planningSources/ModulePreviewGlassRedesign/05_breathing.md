# Этап 5 — Превью BREATHING PRACTICES в стекле

## Описание

`_BreathSpherePreview` уже богатый (золотая шейдер-сфера + корона + риммка) —
самый близкий к HABIT по «материалу». Задача минимальная: **обернуть сферу в
общий стеклянный каркас** (диски + орбита + парящие пилюли), чтобы карточка
встала в один ряд по композиции и глубине с остальными.

## Пользовательский сценарий

Стеклянная сцена: матовые диски + вращающаяся орбита по краю + парящие пилюли,
а в центре — уже существующая дышащая золотая шейдер-сфера с короной и риммкой.

## Логика и поведение

### Герой
- **Существующая шейдер-сфера** (`breathing_sphere.frag`) + корона + `SphereRimPainter`
  — оставить как есть (это эталон «материала»).
- Вписать в единый бокс 150 (сфера 144 — уже сделано), добавить вокруг каркас.

### Совместимость
- Каркас рисуется **за** короной сферы (диски/орбита — фон), пилюли — поверх/сбоку.
- Корона (мягкое свечение) не должна конфликтовать с дисками — подобрать alpha.

### Анимация
- Пульс сферы (уже есть) + орбита/float/пилюли каркаса.
- Reduce-motion → статичная сфера + статичный каркас.

## Затрагиваемые модули

- `operations_control_screen.dart`: `_BreathSpherePreview` — добавить вокруг
  `GlassPreviewScene` (диски/орбита/пилюли), сферу оставить героем.

## Схема данных

Не требуется.

## Этапы реализации

1. Breathing на каркас (диски/орбита/пилюли) под/вокруг существующей сферы.
2. Согласовать короны/диски по прозрачности (без «грязи»).
3. reduce-motion; `flutter analyze`; визуальная проверка (тёмная/светлая).
