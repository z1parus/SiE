# Этап 1 — Каркас «Glass Preview Scene» (фундамент)

## Описание

Вынести стеклянную многослойную сцену из `_HabitCrystalPainter` в
**переиспользуемый каркас**, чтобы каждое превью получало одинаковую «свежую»
глубину (диски, орбита, пилюли, единый свет, тема, reduce-motion), а различался
только **центральный герой-символ**.

## Пользовательский сценарий

Внешне ничего нового на этом этапе — это рефакторинг под капотом: HABIT ARCHIVE
продолжает выглядеть как сейчас, но его «обвязка» становится общим компонентом,
готовым к переиспользованию в meditation/planning/focus/breathing.

## Логика и поведение

Каркас — `GlassPreviewScene` (виджет) + `GlassSceneLayers` (painter-хелперы),
рисующие в порядке:

1. **Матовые диски** — `disc(r*0.96)`, `disc(r*0.80)` (fill+stroke, тема-зависимо).
2. **Плита-свечение** — размытый круг `r*0.60` за героем.
3. **Орбитальный акцент** — `orbitalArrow(angle)` + `dottedArc(angle)` (вращение).
4. **Слот героя** — колбэк/слой, куда модуль рисует свой символ (огранка/сфера/
   кольцо). Передаются: `center`, `radius`, `floatDy`, `gold`, `gold2`, `glass`,
   `isLight`, `t`.
5. **Парящие пилюли** — `floatingPills(t, gold, gold2, count, dataFilled)` с
   последовательным появлением сверху-вниз.

Параметры каркаса:
- `box = 150` (единый размер, уже принят).
- `glass = isLight ? Color(0xFF5B6480) : Colors.white` (видимость на обеих темах).
- `motion` (reduce-motion → орбита/пилюли/float застывают).
- `accent/accentSecondary` из `SieColors`.

### Варианты исполнения
- **A. Локальный микс-ин в экране** (рекоменд. для старта): вынести методы
  `_glassDiscs`, `_orbital`, `_dottedArc`, `_floatingPills` в общий
  `_GlassScenePainter`/функции в `operations_control_screen.dart`; каждый
  модуль-painter вызывает их + рисует героя. Минимум риска, без новых файлов.
- **B. Виджет в `sie_core`** (`GlassPreviewScene` + `HeroBuilder`): чище и
  переиспользуемо вне экрана, но больше работы и связности. Делать, если каркас
  понадобится ещё где-то.

## Затрагиваемые модули

- `apps/central_hub/lib/screens/operations_control_screen.dart` — извлечь общий
  каркас из `_HabitCrystalPainter`; HABIT начинает использовать общий каркас
  (регрессий быть не должно — пиксельно тот же результат).
- (вариант B) `packages/sie_core/lib/src/widgets/glass_preview_scene.dart` — новый.

## Схема данных

Не требуется — чистый UI/рефакторинг.

## Этапы реализации

1. Выделить из `_HabitCrystalPainter` методы каркаса (диски, плита, орбита,
   пунктир, пилюли) в общие функции/painter.
2. Перенести HABIT на общий каркас (визуально без изменений) — регресс-проверка.
3. Зафиксировать публичный «контракт героя» (что получает центральный символ).
4. `flutter analyze`; визуальная сверка HABIT до/после.
