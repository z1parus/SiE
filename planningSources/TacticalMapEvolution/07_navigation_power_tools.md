# Этап 7 — Навигация и про-инструменты карты

## Описание

По мере роста карты (десятки узлов + заметки + изображения + группы из этапов 1–4) холст 4800×4800
становится трудно обозревать. Этот этап делает большую карту **управляемой** и закрепляет статус
карты как **самостоятельного мощного инструмента**: мини-карта, поиск-и-переход, авто-раскладка
(«Прибраться»), зум-под-контент, закрепление позиций.

Чистый UX-этап — без новой бизнес-логики и (почти) без схемы.

## Пользовательский сценарий

1. **Мини-карта** (оверлей, угол экрана): уменьшенная схема всех узлов + прямоугольник текущего
   вьюпорта; тап/перетаскивание по ней → быстрый переход по холсту.
2. **Поиск** (иконка 🔍): строка поиска по названиям узлов/заметок; выбор результата → камера
   плавно центрируется и подсвечивает узел (`_hoverAnim`).
3. **«Прибраться»** (✨): переразложить узлы текущей выбранной под-ветки или всей цели по
   радиальному алгоритму (уже есть `_layoutSubGoalRadial`/`_ensurePositions`), с анимацией; не
   трогает заметки/изображения. Подтверждение (отменяемо), т.к. перезапишет сохранённые позиции.
4. **Zoom-to-fit** (⤢): вписать всю карту (узлы + элементы) в экран — вычислить bounding-box и
   подобрать масштаб/смещение `_tc`.
5. **Закрепить позиции** (🔒): тумблер «lock» — запрещает случайный drag (для презентации/просмотра),
   хранится в `GoalSettings`.
6. **Фокус-узел / «изолировать ветку»**: временно показать только выбранную под-цель и её потомков
   (приглушить остальное) — переиспользует механику Fog of War приглушения.

## Логика и поведение

### Мини-карта
- Новый виджет `_MiniMap` (оверлей): `CustomPainter`, рисующий точки/прямоугольники узлов в
  масштабе, плюс рамку вьюпорта, вычисляемую из `_tc.value` и размера экрана.
- Слушает `_repaint` (узлы двигаются — мини-карта обновляется), но рисует **дёшево** (только точки).
- Тап → пересчёт `_tc` так, чтобы точка попала в центр.

### Поиск
- Локальный поиск по `goal.subGoals`/`tasks`/`milestones`/`mapElements` (in-memory, без сети).
- Переход: `Matrix4` центрирование на логической позиции узла (использует `_positions`),
  `animateTo` через `AnimationController` (плавно), затем `_setHoverTarget(id)`.

### Авто-раскладка
- Переиспользовать существующие функции layout (`_ensurePositions`, `_layoutSubGoalRadial`):
  пересчитать позиции узлов, записать через `saveMapPositions`. Заметки/изображения/группы
  (`mapElements`) **не** трогаются.
- Анимация перехода старая→новая позиция (Tween на `_positions`), уважать `SieMotion.enabled`.

### Закрепление / lock
- Флаг `mapLocked` в `GoalSettings` (JSON-поле, без миграции таблиц) — переиспущенный паттерн
  `updateGoalSettings`. При `mapLocked` drag-хэндлеры узлов/элементов выключаются.

### Edge cases
- **«Прибраться» отменяемо** — сохранить прошлые позиции для undo (как `showUndoSnackbar`).
- **Очень большая карта** — мини-карта семплирует/клампит число точек; поиск — дебаунс.
- **Пустая карта** — мини-карта/поиск скрыты.
- **Производительность** — все оверлеи вне `InteractiveViewer`; мини-карта рисует точки, не виджеты.

## Затрагиваемые модули

| Файл | Действие |
|---|---|
| `apps/central_hub/lib/screens/tactical_map_view.dart` | `_MiniMap` (оверлей+painter); поиск-оверлей + анимированный переход; «Прибраться» (+undo); zoom-to-fit; чтение `mapLocked`; фокус-ветка |

> Новых таблиц нет; `mapLocked` хранится в существующем JSON `GoalSettings` → `schemaVersion` **не**
> меняется.

## Схема данных

Без новых таблиц. `GoalSettings.mapLocked: bool` сериализуется в существующее JSON-поле
`goals.settings` / `LocalGoals.settingsJson`.

## Открытые вопросы

1. **Несколько алгоритмов раскладки** (радиал / дерево-сверху-вниз / таймлайн по дедлайнам)?
   Рекомендация: MVP — существующий радиальный + «tidy»; дерево/таймлайн — расширение.
2. **Сохранять ли «вид» (камеру) между сессиями.** Рекомендация: да, мягко — последний
   зум/смещение в локальные prefs по `goalId` (без БД).
3. **Мини-карта: показывать ли заметки/изображения** или только узлы. Рекомендация: только узлы +
   группы-зоны (легче читать); изображения — точкой.
4. **Жесты** (двойной тап = zoom-to-fit?). Рекомендация: да, двойной тап по пустому месту = fit.
